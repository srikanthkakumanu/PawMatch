
# Kennel capacity by building

| Building         | Total kennels  | Notes                            |
| ---------------- | -------------- | -------------------------------- |
| Main shelter     | 40             | Dogs and cats, mixed             |
| Annex (seasonal) | 15             | Opens May–September only        |
| Foster network   | ~25 (variable) | Not guaranteed — confirm weekly |

Rule of thumb: never plan intake assuming more than 80% of total capacity —
some kennels are always reserved for medical holds.

## What counts toward total kennels

- Main shelter: always.
- Annex: only during May–September.
- Foster network: only the placements confirmed for the current week.
